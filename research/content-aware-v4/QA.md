# 工程与浏览器验收

2026-10-26，数值版本 content-aware-v4.2。研究评测、自动测试与真实浏览器验收分开记录。

## 自动验证

- `npm test`：65/65 个顶层测试通过；其中包括作者34对CIEDE2000参考值、二元图割与alpha移动穷举、完整目标下降、库存与K上限、空位不变、细节预算及消融正交性。部分顶层文件另含多个内部断言，未混为更多独立样例。
- `npm run build` 与 `npm run validate`：通过，28个网页资源，构建后的独立服务器文件683,156字节；响应头、HEAD/404/405和图片代理路由检查通过。无真实AI调用。
- 应用层四组独立测试通过：主体范围及历史图纸恢复；白色格、数量与选择；店家色卡/可用库存；计时、退出恢复、完成记录及不可变快照。它们使用隔离的存储与绘图桩，不冒充浏览器截图验收。
- Worker协议测试覆盖真实纯函数结果、输入缓冲区不被转移破坏、失败/超时/异常的终止和拒绝处理。

## 真实浏览器

在本地构建页面127.0.0.1:5173，通过界面上传研究集的公开宇航员PNG（256×256），选整图、64×64格、均衡、原始风格、18色上限、保留背景。

1. 实际模块Worker生成成功，显示4096颗、18色，保存到本机仓库。
2. 通过网页的“图纸备份JSON”按钮下载结果；文件算法标识为content-aware-v4。4096个色号逐格与独立主实验中同一照片、同一参数的full/K18结果一致。
3. 进入拼豆视图，点R12后正确高亮615颗同色豆；清除高亮、适应缩放和暂停计时均正常。验收记录保持暂停。
4. 返回仓库再点编辑，恢复64×64、18色、均衡与4096颗图纸；源图保留。
5. 页面未记录warn/error控制台日志。没有调用或填写AI接口。

截图保存为交付目录的“豆豆工坊-v4验收.png”，展示本地验收结果。图纸与备份为公开研究照片；未修改用户已有图纸。历史图纸只有在用户重新生成时才应用新版算法。

## 不能从工程验收推出的结论

测试通过不等于每类照片都更好。独立保留组的碎片率目标未普遍达到，草地和视网膜等退步详见RESULTS.md；高阶组件目标不具有全局最优保证，也没有实物拼装计时或用户辨认度试验。
