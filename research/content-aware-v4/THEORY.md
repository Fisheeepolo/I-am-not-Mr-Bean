# 四模块组合的理论边界与研究命题

本文件给出管线层面的推导。各模块的实际参数、近似和伪代码分别见 SAMPLING.md、OPTIMIZER.md；实验协议与数据见同目录评测文件。公式不自动意味着实现获得了论文的全部性能或最优性保证。

## 1. 先固定占位，再优化颜色

已确认的源图前景透明度为 α(p)，目标格 i 与源像素 p 的面积重叠为 aᵢₚ≥0。几何占位覆盖率为

    Aᵢ = Σₚ aᵢₚ α(p) / Σₚ aᵢₚ
    mᵢ = 1[Q₈(255 Aᵢ) ≥ 100]

颜色代表值则为

    xᵢ = Σₚ aᵢₚ α(p) W(p) I(p) / Σₚ aᵢₚ α(p) W(p)

Q₈ 是 Uint8ClampedArray 的8位舍入；保留这一步可避免在阈值附近把连续公式误说成实现的逐位判定。分母为零时为空格。W 只出现在颜色式中，不进入 Aᵢ。因而改变显著性参数、色号预算或空间惩罚均不能改变 m。这是代码应满足的精确不变量。源图的背景分割错误仍可能传播，本模块不能从已删除的信息中恢复主体。

## 2. 加权积分何时能保住一条细线

考虑单格内部只有细线颜色 f 与背景色 b，细线占有效面积比例 q∈(0,1)，细线相对于背景的平均权重比为 r>0。则

    x = θ f + (1−θ)b，θ = rq / (rq + 1−q)

由于 dθ/dr = q(1−q)/(rq+1−q)² > 0，增加细线相对权重使代表色严格向细线色移动。

若某个后续判别规则在 θ≥t 时选细线色，则充分且必要条件为

    r ≥ t(1−q) / ((1−t)q)

在两端颜色的欧氏最近邻二选一模型中，t=1/2，从而 r≥(1−q)/q。例如细线占1/4格时，需要细线平均权重至少为背景3倍。这个阈值只适用于该简化模型；真实色卡有多个候选，DE2000 沿混合路径也非线性，应直接计算其判别边界。

对 W=exp(β₁S+β₂G)，若 S,G∈[0,1] 且 β≥0，则任意权重比不超过 exp(β₁+β₂)。因此任意窄线不可能都获得保证：当 q<1/(1+exp(β₁+β₂)) 时，即使达到最大权重比，也不足以越过该欧氏二选一边界。若边界两侧梯度相同、显著性没有区分线与底，则 r=1，加权不带来改善。

权重上界、源图可见性、细线网格相位和色卡可用性共同限制可保全程度。实验应同时测保留细节与新增伪边缘，不能只展示成功的眼睛示例。

## 3. 平滑与细节目标存在竞争

各向异性预处理利用局部结构张量的特征向量确定切向与法向，优先沿切向聚合。散焦代理来自不同频段能量的比例，但低纹理、压缩、运动模糊与光学散焦并不唯一对应。故将其用于连续混合系数，不把它当成可信的语义背景掩码。

相对于均匀强平滑，结构和显著性抑制有机会保护五官；相对于完全不平滑，它可能减少背景渐变的量化碎块。这两项是待测假设，不能由滤波形式本身推出视觉改善。

## 4. 受限颜色分配与高阶工艺项

在固定有效格 V={i:mᵢ=1} 上，标签 zᵢ 仅来自物理库存 P 中的子集 S，|S|≤K。定义

    E(Z|S) = Σᵢ Dᵢ(zᵢ) + λΣ(i,j) wᵢⱼ·1[zᵢ≠zⱼ]
             + γΣC∈CC(Z) 1[1≤|C|≤2]·u(C)

D 是显著性加权感知颜色损失。w≥0，随强图像边界衰减。CC(Z) 是同色四连通组件。实现中 u(C)=1[C非保护]·(1−mean_C(s))²·(1+0.5 mean_C(f))，γ 对应模式参数 η；按组件收取一次阶跃罚，不再乘 |C|。保护门控及其版本化修订在 OPTIMIZER.md 中逐项记录。紧凑度和孤岛率是评估代理，不能等同实际人类拼装时间。

DE2000 可用于任意非负 unary 数据项；无需满足标签度量。pairwise 使用 Potts 标签度量，才能在固定 S 时得到可图割的二元 expansion 子问题。把 DE2000 本身当作 pairwise 标签距离并声称满足三角不等式是不成立的推理。

组件集合 CC(Z) 随标签变化，孤岛阶跃项属于高阶非局部项。普通 pairwise 图割不能精确求其最小值。实现应明确分开 pairwise expansion 与高阶合并提案，并对宣称下降的目标实际求值。只接受严格下降、又只有有限标签状态时，可得有限终止（不循环）；设置固定迭代上限时，只保证已接受步下降，不保证已达到全部邻域的局部极小。

### 开发失败引出的局部边界预算

v4.1 开发集发现，弱小特征改成周围颜色的数据损失小于所节省的 Potts 边界代价。v4.2 对有源图支持的1–2格小结构增加固定边界预算。具体筛选门槛在 OPTIMIZER.md 中冻结；不把这些门槛解释为语义识别。

令初始化时组件 C 的标签为 c₀，定义所有其他已选物理色中的最小统一重着色损失：

    m_C = min_{c≠c₀} Σ_{i∈C} [D_i(c)−D_i(c₀)] > 0
    B_C = Σ_{(i,j): i∈C,j∉C} a_ij

对合格组件把跨界边乘 min(1, κm_C/B_C)，κ=1/2；多个组件共享的边只会继续缩减。最终仍有 B_C≤κm_C，边权在标签优化开始之前固定。其余标签固定、仅将 C 全体统一改为某一其他色时，Potts 项最多减少 B_C，故

    Δ(D+V) ≥ m_C−B_C ≥ (1−κ)m_C > 0。

这是局部数据项与边界项的严格界。它不覆盖同时修改其他格的全局移动、组件内不同格改成不同标签，或高阶 H 因邻近组件合并而下降的情形，因而不能宣称完整能量下细节不可改变。它也可能保护真实噪点，须用关闭此模块的消融量化代价。

## 5. 色号预算保证与不可兼得情形

第一阶段从 P 内选≤K个设施；之后所有像素重标记、expansion和组件合并的候选都限制在 S 中。由归纳，任何一步后的使用色号集合均为 S 的子集，从而全图颜色数≤K，且不产生库存外的虚拟色。由于 DE2000 不是平方欧氏距离，用 Lab 均值替代整个簇并不能保证保持原目标；离散重选需对真实代价或明确披露的近似分布求和。

如果图像有很多语义必要的单颗眼睛/高光，保护它们就可能使原始孤岛率高于0.5%；若 K 小到连这些点与主体色都容纳不下，任何算法都无法同时满足全部颜色保真目标。应报告预算下的结构、色差和工艺代理 Pareto 取舍，而不是修改评价分母以得到达标结果。

## 6. 可证性质与实验命题分开

可由代码不变量和小规模穷举验证：占位保持、库存合法、K硬上限、确定性、有限数值、相应能量的下降、二元cut最优性。

必须靠独立样例或人类实验检验：神态保真、照片看起来更像、背景更干净、碎豆可接受、实体拼装更快。Canny/XDoG 是自动结构参照，并非人工边缘真值。现阶段没有参与者研究或实物拼装测时，不作相关效果声明。

物理色卡约束指输出必须来自所选库存的既有色号。当前内置 MARD 色卡的 RGB 是社区整理的屏幕参考值，未对实物豆子做分光测色或批次校准。sRGB→CIELAB→ΔE00 因而评价的是这些参考值下的色彩误差，不能外推为真实材料在任意照明下的色差。库存合法性是硬约束，实物颜色准确性仍需标定验证。

## 7. 总体算法与复杂度

```text
输入：主体范围内 RGBA 图像 I，可用物理色卡 P，目标网格尺寸，正整数预算 K
1. 用已确认的主体范围与既有分割策略固定源 alpha；不依据“接近白色”删除格子
2. 在源尺度提取多尺度结构、梯度、结构张量、低高频比代理及置信度
3. 按局部方向和结构信息作稀疏各向异性预抽象；逐字节保持 alpha
4. 用几何面积积分得到占位，用显著性加权积分得到代表色
5. 计算可用色卡的加权设施代价；贪心增色 + 离散中心更新，选 ≤K 色
6. 构建固定的非负四邻边和逐格数据项；执行有限轮 alpha-expansion
7. 对每个提案核算完整目标；再尝试小组件合并，只接受完整目标下降
8. 返回固定空位上的合法色号、实际用量和逐阶段能量诊断
```

令源像素数 M、有效豆格数 N、选色代表样本数 R、物理色卡大小 P、预算 K。固定次数可分离卷积及13点稀疏抽象为 O(M)；取样按实际交叠访问源像素。选色矩阵空间 O(RP)，本实现上限为 3,000,000 项；贪心选色 O(KRP)，有限轮离散中心更新 O(RP)。最终逐格单色代价空间 O(NK)，四邻图 O(N) 边。图割耗时为至多 2K 次二元最大流加上高阶目标复算；这里不承诺线性最坏复杂度，Dinic 在一般图的最坏界为 O(V²E)。工程实测时间与复杂度界分别报告。

网页通过模块 Worker 执行整条数值管线。任务输入是自有副本，完成、错误或超时均终止 Worker；主界面保持绘制与响应能力。Worker 是执行方式，不改变数值目标，也不提升算法的最优性保证。
