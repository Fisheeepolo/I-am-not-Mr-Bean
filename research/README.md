# 非 AI 拼豆图纸转换研究

本目录保留可复现实验、旧算法和评价数据。目标是在**固定网格、固定色卡、固定颜色预算**下改善视觉保真，同时减少不必要的小色块与换色操作。指标是工程代理指标，不是用户实验结果；不能用它们推断真实拼装时间，更不能证明对所有图片最优。

## 问题与方法

旧量化器先逐格寻找色卡中的最近 Lab 颜色，再保留出现次数最多的 K 色。这种频率裁剪可能舍弃面积很小却对识别重要的颜色，且忽略空间邻域。旧版完整函数原样保存在 `baseline-engine.js`，来源为网站提交 `d92334a85f157aea1279b6a14597a5fee489f124`。

新实现分为独立的取样和选色/整理两层，便于消融：

1. 原图按 alpha 预乘的真实面积积分降至豆子网格，透明像素隐藏的 RGB 不污染边缘；可选局部对比恢复。
2. 在真实可用色卡上按感知误差下降量选择颜色，以取代简单频率截断。
3. 结合局部对比约束做空间整理，减少弱小碎片，保留强对比小标记。细节、均衡、好拼三档改变取舍，不改变色号或透过透明区域造豆。

实现是适配浏览器与固定商用色卡的工程启发式，**不是下列论文的完整复现**，未使用训练模型或外部 AI 接口。

### 数学目标与固定参数

令输入格子的 Lab 为 `xᵢ`，选择的色卡颜色集合为 `S`，每格标签为 `zᵢ`。选色阶段以 `Σᵢ wᵢ min(c∈S) ||xᵢ−c||²` 为目标方向，约束 `|S|≤K` 且 `S` 必须来自可用库存。局部权重为 `wᵢ=1+min(2,max邻格 ΔE76/18)`，高对比结构最多有 3 倍权重。这不是眼睛或文字识别，因此高对比噪声也可能被保护。

为限制浏览器成本，先按最接近的完整色卡颜色聚合，使用各组的加权中心与总权重作为代理；逐次选择误差收益最大的颜色，再执行最多两轮受限色卡 Lloyd 更新。该贪心/局部改进过程不保证全局最优，也没有宣称理论近似界。

整理阶段采用边缘敏感的 Potts 代价：`Σᵢ wᵢ ||xᵢ−c(zᵢ)||² + Σ相邻(i,j) λ exp(−||xᵢ−xⱼ||²/(2σ²)) [zᵢ≠zⱼ]`。每格候选只取当前及邻格标签，棋盘顺序进行有限局部更新。细节档 `(λ,σ,轮数)=(0,9,0)`，均衡 `(35,9,3)`，好拼 `(95,14,5)`。输入强边界降低合并代价，从而更倾向保留它。

取样使用 sRGB 通道上的 alpha 预乘面积平均（不是物理线性光积分）。局部恢复使用目标格与邻域中位数的差，受源格颜色上下界限制。恢复增益为细节 1.5、均衡 1.2、好拼 0.35；均衡/好拼还要求源格中前两种 RGB 16 档颜色的集中度从 70% 到 90% 逐渐放行，抑制照片连续色调被过度锐化。透明覆盖率保持取样原值，原尺寸输入直接复制。

## 相关研究与本项目的取舍

- Kopf、Shamir、Peers，*Content-Adaptive Image Downscaling*，ACM TOG 2013。[作者项目页](https://johanneskopf.de/publications/downscaling/)；[作者提供的论文](https://www.cs.wm.edu/~ppeers/publications/Kopf2013CID/Kopf_SIGGRAPHAsia2013.pdf)。该研究将取样核与图像内容关联，说明保锐与抗混叠之间存在取舍。本项目借鉴“取样不能完全忽略局部结构”的思路，未实现其 EM 优化。
- Gerstner 等，*Pixelated Image Abstraction*，NPAR 2012。[作者项目页](https://cragl.cs.gmu.edu/pixelate/)；[论文](https://gfx.cs.princeton.edu/gfx/pubs/Gerstner_2012_PIA/Gerstner_2012_PIA_full.pdf)。该方法联合处理低分辨率特征映射与色彩缩减。本项目据此将“仅按颜色频率缩减”视为不足，但没有语义识别，也不能保证脸部或文字的可识别性。
- Puzicha、Belongie，*Model-based Halftoning for Color Image Segmentation*，ICPR 2000。[作者单位论文](https://vision.cornell.edu/se3/wp-content/uploads/2014/09/icpr00.pdf)。空间颜色量化提供考虑邻域而非独立逐像素的思路；拼豆需要一个格子对应一种实色，因此本项目有意不使用依靠密集混点来模拟中间色的抖动。

论文中的用户研究结论属于对应论文，不能移用为本站算法已验证的人体工效结论。

## 冻结的数据与实验协议 v1

`prepare-fixtures.py` 使用 Pillow 生成确定性样例并写出原始 RGBA、PNG 与 `fixtures.json`（含 SHA-256）。12 张输入在第一次评估前划分为：

- 开发组 7 张：小面积眼睛、低对比噪声平涂、细线圆弧、渐变、透明徽章、原尺寸像素图、NASA 宇航员照片。
- 保留组 5 张：另一尺寸的人脸、另一随机种子的噪声平涂、风景平涂、Chelsea 猫照片、火箭照片。仅在参数冻结后首次运行，不用于当轮调参。

每张图运行三种约束：MARD 291 色中最多 8 色、最多 16 色、固定 12 色店铺子集中最多 8 色。店铺子集由预先给定的黑白、暖色、绿蓝紫等 RGB 在同一 MARD 色卡中匹配，编号来自真实参考色卡。所有方法对同一图片使用相同尺寸、透明阈值 100、关闭去背景与风格调整，以免混入其他功能的差异。

每种约束比较七种方法：旧量化器、同一网格输入的新三档、从源图取样开始的新三档。旧量化器与“同网格”组均使用**明确的 alpha 预乘面积平均**；这消除了浏览器滤镜实现差异，但不是旧浏览器 `imageSmoothingQuality='high'` 的逐像素复刻。应把同网格组视为量化算法的主要受控证据，全流程组同时观察取样带来的收益和代价。

运行时间为同一 Node.js 进程内 1 次预热后的 3 次运行中位数，包含该方法使用的取样与量化；不包含解码、界面绘制、网络、浏览器调度。结果记录 Node 版本与源文件散列；不同机器不可直接比较毫秒数。

代码散列使用 UTF-8 文本并将 CRLF/CR 规范为 LF 后计算 SHA-256，避免 Windows Git 换行设置造成假差异。首轮原始字节散列保留在结果的 `rawSourceHashes` 中，规范化前已逐个核对当前文件与实测时的原始散列一致。

## 指标定义

| 指标 | 定义 | 解读限制 |
|---|---|---|
| meanDeltaE76 | 同一面积平均参考与输出实色的逐格 CIE Lab 欧氏距离，前景交集取均值 | 越小越接近面积平均，但面积平均本身会模糊细线；不是完整人眼色差模型 |
| edgePrecision / Recall / F1 | 参考与输出中 4 邻接颜色 ΔE76 ≥ 20 的边是否出现在同一位置 | 只衡量强边界；渐变被量化出的阶梯可算假边；轮廓移动一格会被惩罚 |
| silhouetteIoU | alpha ≥ 100 的参考前景与输出非空格子的交并比 | 只衡量几何占位，不验证语义 |
| smallComponents / smallCells | 4 连通同色块面积为 1–2 格的块数 / 格数 | 小眼睛也会计入，不能一概越少越好 |
| weakSmallCells | 上述小块与相邻非空色块的平均边界 ΔE76 < 20 时计入 | 更接近低对比杂点，但阈值是启发式 |
| rowTransitions | 每行相邻非空格颜色不同的次数 | 拼装操作复杂度代理，未测量人类换色耗时 |
| markersPreserved | 合成眼睛位置的输出与预定眼睛颜色 ΔE76 ≤ 15 的数量 | 仅针对已标注的合成眼睛，不评估照片中的真实眼睛 |
| usedColors / beads | 实际色号数量 / 非空格数 | 约束检查，而非单独的质量分数 |

不将各指标合并为一个“总分”，因为抹掉细节可降低碎片和换色却伤害识别。评价需同时看原图、结果和各指标。

## 复现

环境：Node.js（无额外 npm 依赖）；准备 PNG 需要 Python 与 Pillow。照片原始文件已随本研究目录保存，离线可复现。

```text
python research/prepare-fixtures.py
node research/run-benchmark.mjs --split=development
node research/run-benchmark.mjs --split=heldout
node research/summarize-results.mjs
python research/render-comparison.py
```

结果写入 `research/results/{split}.json`、`.csv` 和可直接打开的自含 `{split}-comparison.html`。JSON 中保留每张图每种方法的原始测量值与代码散列；HTML 显示全部输入，没有只挑改善样例。

本轮结果和分组表见 `results/RESULTS.md`，两组实际输出总览见 `results/*-contact-sheet.png`。这些 PNG 由同一实验 HTML 中的实际输出格子渲染，未重画或替换算法结果。

## 尚未覆盖

当前是小规模、固定图像的工程评估：没有招募拼豆用户、没有盲评、没有实测拼装工时，没有校准显示器/相机/实物色差，也没有测试所有图像类别、店铺色卡和极低分辨率。文本、头发、纹理、人脸表情以及一格以下的结构仍可能损失。后续科研级验证应扩充未见图像与尺寸、盲测辨认度，并计时记录真实拼装中的定位错误和换色次数。
